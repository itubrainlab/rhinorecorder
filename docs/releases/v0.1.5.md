Rhino Recorder acquires, views, records and streams EEG from the g.tec **Unicorn Hybrid Black**, like g.tec's Unicorn Recorder, on Windows, macOS and Linux. It runs on [g.Pype](https://gpype.gtec.at) with the licence-free [gpype-rhino](https://github.com/itubrainlab/gpype-rhino) Bluetooth driver.

## What's changed in 0.1.5
- **Windows: the headset appears in the device list.** Windows describes a Bluetooth COM port only as "Standard Serial over Bluetooth link", so 0.1.4 never listed the headset. Rhino Recorder now uses [gpype-rhino 0.1.2](https://github.com/itubrainlab/gpype-rhino/releases/tag/v0.1.2), which finds the headset from the port's device, and lists it with its port, for example `UN-2024.10.18 (COM5)`. A headset name typed in the dialog, or `--device`, also finds its port.

### From 0.1.4
- **Windows package:** a zip you unpack and install with `install.cmd`, for the current user, with no administrator rights.
- **Packages for all three platforms built by GitHub Actions,** each installed on its own platform and checked on the simulated headset before it is published.

`SHA256SUMS` lists the checksums.

**First launch needs an internet connection.** The packages contain their own Python, Rhino Recorder and gpype-rhino, but not g.Pype: the g.tec Non-Commercial License does not allow g.Pype to be redistributed in a bundle. On first launch the app downloads g.Pype and the other libraries from PyPI (several hundred MB, a few minutes), at the versions this release was tested with. Later launches start directly.

### Windows
Unpack the zip and double-click **install.cmd**, then open Rhino Recorder from the Start menu. Pair the headset in Settings → Bluetooth & devices first. The device dialog lists it with its COM port, for example `UN-2024.10.18 (COM5)`; if it is not listed, enter the port (the included README.txt says where to find it). **Finding the headset on Windows has been tested with Windows' port IDs and registry reproduced, but not yet on a Windows PC with a headset.** Please report problems as issues.

### macOS
Open the DMG and drag **Rhino Recorder** to Applications. The app is not notarized by Apple, so the first time, right-click it and choose **Open**. Pair the headset in the Bluetooth settings first; macOS asks once for Bluetooth access.

### Linux
Pair the headset in the system's Bluetooth settings (or with `bluetoothctl`: `scan on`, `pair <address>`, `trust <address>`), then:
```bash
tar -xzf RhinoRecorder-0.1.5-linux-x86_64.tar.gz
cd RhinoRecorder-0.1.5-linux-x86_64
./install.sh
```
No administrator rights are needed; it adds a menu entry and a `rhino-recorder` command. Rhino Recorder finds the headset by name, with no `rfcomm bind` or `dialout` group needed. See the included README.txt.

## What it does
- Unicorn Recorder's 19 channels in the same order (EEG 1–8, accelerometer, gyroscope, counter, battery, validation, DT, TRIG)
- A sweeping data viewer with per-channel signal quality, filter and notch presets, and OSCAR artifact removal
- A trigger row, with each trigger value in its own colour
- Raw and processed recordings as CSV and BDF+, started and stopped at a shared sample
- UDP trigger input (port 10000), UDP and LSL outputs (10001, 10002)
- A simulated headset for trying it without hardware (`rhino-recorder --simulate`)
